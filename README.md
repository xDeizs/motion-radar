## Бесплатный AI — что это означает

По умолчанию платные AI API, подписки и скрытые публичные прокси не используются. Необязательные собственные API версии 7 описаны выше и запускаются только явно. Для прежнего локального AI используется **Qwen2.5-0.5B-Instruct** на CPU, локально или на стандартном GitHub Actions runner. Веса — Apache-2.0; версия модели закреплена в `scripts/enrich.py`, `trust_remote_code=False`.

- `analysis.engine = extractive`: выдержка из RSS + темы по правилам. **Не AI.**
- `analysis.engine = transformers`: настоящий семантический отбор предложений локальной открытой моделью.
- `analysis.engine = ollama`: отбор в вашем локальном Ollama через `127.0.0.1:11434`.

Маленькая CPU-модель не равна большим платным моделям. Чтобы не публиковать выдуманные пересказы, она возвращает только номера выбранных предложений; сайт показывает соответствующие фрагменты исходника, без машинного перевода. Язык фрагментов остаётся языком оригинала. Всегда проверяйте оригинал. За один запуск обрабатываются до 4 новых статей; результаты кэшируются по хешу входных данных. При сбое модели сохраняется обычная RSS-выдержка, а не выдуманный AI-результат.

Первое скачивание весов — около 1 ГБ; нужны память, диск и время CPU. Стандартные GitHub-hosted runners для публичных репозиториев обычно бесплатны в рамках правил GitHub. Это не обещание безлимитных вычислений: учитывайте условия аккаунта и квоты. Платные runners здесь не используются.

## Локальный AI через Transformers

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install torch==2.9.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements-ai.txt
python scripts/enrich.py --backend transformers --fetch-articles --limit 4
```

На Windows активация: `.venv\Scripts\activate`. Без `--fetch-articles` модель использует только название и RSS-фрагмент; это видно в интерфейсе. Для публичного HTML учитываются список разрешённых доменов и `robots.txt`; при запрете или ошибке сбор не обходит ограничение.

Если уже установлен Ollama и скачана модель `qwen2.5:0.5b`:

```bash
python3 scripts/enrich.py --backend ollama --fetch-articles --limit 4
```

Сайт не обращается к Ollama из браузера. Обработка делается скриптом, результат сохраняется в статическом снимке. Личные заметки браузера в обработку не включаются.

## GitHub Pages

1. Создайте или выберите **свой публичный репозиторий** с веткой `main`.
2. Загрузите **содержимое** этой папки в корень, включая `.github/`. Не загружайте только ZIP.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. В **Actions** разрешите workflow и выполните **Update and publish Motion Radar → Run workflow**. Флажок `ai` включает локальную CPU-модель; выключенный флажок публикует сайт без нового AI-прогона.
5. Адрес появится в deployment `github-pages`. После этого расписание запускается каждые 6 часов; GitHub может задерживать задания и приостанавливать расписания неактивных репозиториев.

На push выполняется обычное обновление без установки модели. По расписанию AI-разбор включается только при `ENABLE_LOCAL_CPU_AI=true`; вручную — только с `ai=true`. По умолчанию CPU AI выключен. Секреты не нужны: встроенный `${{ github.token }}` используется только для GitHub API и сохранения снимка. Личный PAT не добавляйте в HTML, JSON или коммиты.

**Архив не является деплоем.** Подтверждённый репозиторий — `xDeizs/motion-radar`; успешную публикацию проверяйте в GitHub Actions и deployment `github-pages`.

## Источники и инструменты

- `config/sources.json` — RSS/Atom, категория, лимит, необязательный фильтр `include`.
- `config/catalog-watchlist.json` — известные GitHub-инструменты, skills и плагины.
- `config/watchlist.json` — отдельная конфигурация периодического watcher; её схема не используется для каталога.
- `config/discovery.json` — ограниченные поиски GitHub; не бесконечный скрейпинг.
- `data/feed.json` — публичный снимок, включая краткие разборы.
- `data/analysis.json` — кэш кратких разборов, без полного текста статей.
- `scripts/enrich.py` — темы, HTML-extraction, локальный AI, валидация и кэш.
- `web/radar.js`, `web/radar.css` — новый слой интерфейса; существующий дизайн не переписан.
- `docs/RESEARCH.md` — Agent Reach, проверенные подходы и границы автоматизации.
- `docs/HISTORY-v5.md` — исходная документация архива; исторические заявления не подтверждают текущую публикацию.

## Ограничения и безопасность

- X/Reddit: ручные ссылки по умолчанию; собственные официальные API — отдельные opt-in адаптеры только в приватную очередь. Никакого автоматического входа, чтения cookies и обхода paywall.
- Не все плагины, редакторы, модели или ассеты бесплатны для любых целей. Каталог показывает происхождение и лицензию, а не подменяет их общим обещанием.
- Недоверенный HTML/AI-текст отображается как текст, не исполняется. Не устанавливайте каталогизированный код без собственной проверки.
- Заметки и закладки живут в вашем браузере; очистка хранилища удалит их. Делайте экспорт для переноса.
- Доступность источников, бесплатных сервисов и внешних лицензий со временем меняется.
