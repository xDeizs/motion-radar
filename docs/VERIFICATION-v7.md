# Motion Radar 7 — проверка выпуска

## Реально проверено

- Живой сбор: 6 запросов к публичному GitHub, 30 позиций репозиториев (по 5 на тему). Только метаданные; код не установлен и не запускался.
- Тематический снимок: 55 результатов по 6 темам, включая совпадения из существующего RSS-снимка. Это позиции по темам, не обязательно 55 уникальных материалов. Полного охвата интернета или семантической точности поиска не обещаем.
- Прежние 13 лент, 25 статей, 18 выбранных инструментов и 2 локальных AI-разбора сохранены из версии 6; повторный запуск CPU-модели в версии 7 не выполнялся.
- 6 редакторских гайдов составлены по документации. 3 социальных примера найдены публичным веб-поиском; прочитаны поисковые фрагменты, не видео/комментарии/весь код.
- 72 offline unit-теста прошли: прежние парсеры/медиа/AI, публичный scope, отсутствие сетевых вызовов без ключей/согласия, запрет redirects, allowlist API-hosts, остановка при rate limit, разделение публичного снимка и приватной социальной очереди, проверка ID Gemini, пустые секреты Postman.
- 96 браузерных проверок прошли в Chromium на 1440 и 390 px: 36 прежних + 60 новых. Темы, вкладки, фильтры, гайды, загрузки, модальные окна, закладки, пустые/ошибочные запросы, ссылки, доступность Postman-коллекции и инструкции.
- Ошибок JavaScript и горизонтального переполнения страницы в проверенных сценариях нет. Визуально просмотрены новые темы/гайды desktop и mobile, модальное окно и полные карточки условий. Старый neon-дизайн, hero и сцены сохранены.
- YAML workflow синтаксически проверен. Публичная сборка перечисляет конкретные файлы; `.private/` и секреты не публикуются.

## Не проверено в живых аккаунтах

- Gemini, X и Reddit API **не вызывались с пользовательскими ключами**. Адаптеры проверены на mock/fixture-ответах, не на оплачиваемом доступе. Тариф, квоты, одобрение Reddit и конкретная модель требуют проверки владельцем перед включением.
- Postman Enterprise не подключён и его права/лимиты не подтверждены. Коллекция содержит пустые секретные переменные.
- Ни один гайд не исполнялся в пользовательском Claude/Grok/Grok Bot; экспортные возможности и цены зависят от аккаунта и региона.
- GitHub push, Actions и Pages deployment не выполнялись. ZIP не равен работающему опубликованному сайту. Поле topic и расписание заработают после публикации в своём подтверждённом репозитории.
- Социальная очередь не является compliance-архивом. Нужны разрешённый use case, проверка правил хранения/удаления и отдельное решение о публикации. В публичный снимок она не включается.
- Полного аудита сторонних репозиториев, всех браузеров и исчерпывающего интернет-индекса нет.

## Воспроизведение

```bash
python3 scripts/decode_motion_assets.py
python3 -m unittest discover -s tests -v
python3 scripts/update.py --render-only
python3 -m http.server 8000 --bind 127.0.0.1
```

В другом терминале, с установленными devDependencies и Chromium:

```bash
CHROMIUM_PATH="$(command -v chromium)" node tools/qa.mjs http://127.0.0.1:8000
CHROMIUM_PATH="$(command -v chromium)" node tools/qa-topics.mjs http://127.0.0.1:8000
```

API и биллинг: `docs/API_SETUP.md`. Историческая проверка v6: `docs/VERIFICATION-v6.md`.
