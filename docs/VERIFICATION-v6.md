# Motion Radar 6 — проверка выпуска

## Реально проверено в этой сборке

- Сбор открытых данных: **13/13** RSS/Atom-источников ответили, **32** материала, из них **25** статей.
- Каталог: **18** выбранных GitHub-инструментов/skills/плагинов и **12** поисковых кандидатов. Это метаданные и ссылки, не аудит стороннего кода.
- Локальная CPU-модель Qwen2.5-0.5B-Instruct была установлена в отдельном окружении и действительно запущена. В снимке **2** успешных AI-отбора фрагментов; остальные записи не выдаются за AI.
- Слабые экспериментальные свободные пересказы были удалены. Финальная модель возвращает только индексы исходных предложений; публикуются соответствующие фрагменты, а не выдуманный перевод.
- **53** offline unit-теста: парсинг, безопасные URL, статусы, кэш, ограничения AI, robots.txt, HTML-extraction, лицензии/медиа/lock-файлы.
- **36** браузерных сценариев в Chromium: все 9 вкладок при ширине 1440 и 390 px, разборы, пустой поиск, экспорт Markdown, закладки, локальная заметка с тестовым HTML-текстом, сохранение после перезагрузки, 3 лабораторные сцены и экспорт HTML.
- Ошибок JavaScript в этих сценариях не было; горизонтального переполнения страницы не обнаружено.
- Визуально просмотрены hero, обзор desktop/mobile, код/skills, референсы, лаборатория, знания, бесплатная библиотека, предложения, закладки, мобильный разбор и светлая тема.
- Исправлены старые конфликты CSS: скрытые фильтры, сжатая сцена лаборатории и полная ширина заметок; перенос подписи на телефоне; видимость выбранной вкладки.
- YAML GitHub Actions синтаксически проверен. Локальная сборка и восстановление медиа проверены тестами.

## Граница проверки

Проверка локальная. **В GitHub ничего не опубликовано, workflow в аккаунте владельца не запускался.** Сначала нужно подтвердить репозиторий и доступ. Расписание начнёт работать после публикации и включения Actions/Pages.

Все источники внешние: будущая доступность не гарантируется. Полного аудита сторонних плагинов, моделей и всех браузеров не проводилось. X/Reddit не скрейпятся, cookies не читаются, платные API не используются.

## Воспроизведение

```bash
python3 scripts/decode_motion_assets.py
python3 -m unittest discover -s tests -v
python3 scripts/update.py --render-only
python3 -m http.server 8000
```
