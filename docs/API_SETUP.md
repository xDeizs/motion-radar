# Motion Radar 7 — источники, API и реальные ограничения

Сайт статический. Он не обещает собрать весь интернет, не содержит пользовательских ключей и не запускает серверный сбор кнопкой в браузере. Предпросмотр и ZIP не означают публикацию. Условия ниже проверялись по документации 1 ноября 2026; они могут меняться.

## Что уже работает без ключей

- 13 существующих RSS/Atom-лент и прежний каталог сохраняются.
- 6 тем в `config/topics.json`: Claude Motion, Claude + Remotion, Grok Imagine, Web motion, Blender и ComfyUI.
- `scripts/collect_topics.py`: фильтр публичного RSS-снимка плюс первая страница поиска публичных репозиториев GitHub, максимум 5 результатов на тему по умолчанию. Кэш — 6 часов; ошибка не выдаётся за успешное обновление.
- 6 редакторских гайдов со ссылками на первоисточники, шагами, промптами и ограничениями.
- 3 примера из публичного веб-поиска по X/Reddit: ссылки и короткие редакторские описания. Прочитаны поисковые фрагменты, не вся ветка/видео/код. Это не подключённый поток социальных API.
- Официальные условия Gemini free tier и Notion Business trial — не украденные ключи, не гарантированные кредиты конкретного аккаунта, не бессрочная акция.

```bash
python3 scripts/decode_motion_assets.py
python3 scripts/update.py --render-only
python3 scripts/collect_topics.py --topic remotion --providers github
python3 -m http.server 8000 --bind 127.0.0.1
```

Любая обычная тема поддерживается в кавычках:

```bash
python3 scripts/collect_topics.py --topic "Blender product animation" --providers github
```

Не вводите секреты в тему: она попадает в публичный поисковый запрос и снимок. Для полностью офлайн-пересборки добавьте `--offline`. `--force` обновляет GitHub до истечения кэша, но не обходит блокировку API в текущем запуске. Не запускайте параллельно несколько сборщиков по одному каталогу.

## Кнопки в браузере

«Показать снимок» выбирает уже собранную тему; не скачивает весь интернет. Кнопки Google/GitHub/Reddit/X открывают ручной поиск. «Скачать план сбора» сохраняет Markdown с командой для вашего компьютера. Свежий пользовательский запрос требует запуска CLI/Actions. Для серверной кнопки понадобится отдельный авторизованный backend и лимит расходов; он не развёрнут.

## Собственные секреты

Для локального запуска передайте переменные окружения средствами своей ОС/менеджера секретов. В GitHub используйте **Settings → Secrets and variables → Actions**. Не кладите значения в HTML, JSON, source code, коммиты, URL-параметры, публичные Actions inputs или чат. Сборщик никогда не печатает заголовки авторизации, тексты ошибок провайдеров или значения переменных.

| Переменная | Назначение |
| --- | --- |
| `MR_GITHUB_TOKEN` | Необязательный собственный токен для чтения публичных метаданных. Без него GitHub работает анонимно в своих квотах. В Actions используется временный `github.token`. Запрос принудительно ограничен `is:public`; приватные результаты отбрасываются. |
| `GEMINI_API_KEY` | Необязательный ключ своего проекта Google AI Studio. Только AI-отбор существующих ID из публичных RSS/GitHub-фрагментов, не веб-поиск. |
| `X_BEARER_TOKEN` | Необязательный собственный доступ к X API. Чтение может оплачиваться; нужно `--allow-metered`. |
| `REDDIT_ACCESS_TOKEN` | OAuth access token для одобренного Reddit use case. Скрипт не создаёт приложение, не получает новый токен и не обходит процедуру одобрения. |
| `REDDIT_USER_AGENT` | Честный идентификатор собственного Reddit-приложения по правилам Reddit, например платформа/приложение/версия и ваш username. Не чужая личность. |

### Gemini: AI-отбор, а не доступ ко всем сайтам

1. Создайте ключ в своём [Google AI Studio](https://aistudio.google.com/api-keys).
2. Проверьте [тариф конкретной модели](https://ai.google.dev/gemini-api/docs/pricing) и свои [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits). По таблице Google free-tier данные некоторых моделей используются для улучшения продуктов; приватные заметки и социальная очередь не отправляются.
3. Выберите модель, доступную именно вашему проекту. В конфигурации указан `gemini-3.5-flash-lite`; при необходимости измените через `--gemini-model`.
4. Только после проверки биллинга запустите:

```bash
python3 scripts/collect_topics.py --topic remotion --providers github,gemini --allow-metered
```

За один запуск максимум 3 вызова Gemini, до 30 исходных карточек и 512 output tokens на вызов. Это **не денежный лимит**; настройте квоты и бюджет у провайдера. Сгенерированный произвольный текст не публикуется: принимаются только ID существующих карточек. AI-отбор виден в снимке как список ID и статус модели. Модель не подтверждает достоверность текста источника. Ошибка/невалидные ID оставляют обычный снимок. Без своего ключа и флага вызовов нет.

Google Search grounding у Gemini существует, но **в этой версии не подключён**: у него отдельные правила тарификации, отображения источников и хранения результатов. Сам ключ Gemini не предоставляет право скрейпить X, Reddit или закрытые репозитории. [Документация grounding](https://ai.google.dev/gemini-api/docs/google-search), [generateContent](https://ai.google.dev/api/generate-content).

### X: ограниченный recent search → приватная очередь

Получите доступ и Bearer token в своём [X Developer Console](https://console.x.com/), проверьте [цены и spending limit](https://docs.x.com/x-api/getting-started/pricing). Не включайте auto-recharge без необходимости.

```bash
python3 scripts/collect_topics.py --topic remotion --providers x --allow-metered
```

Один запрос recent search на тему, 10 постов в ответе API; в очередь попадает максимум 5 по умолчанию. Провайдер может считать весь ответ и другие единицы тарификации — это не обещание точной суммы. Recent search охватывает последние 7 дней, не весь архив. [Endpoint](https://docs.x.com/x-api/posts/recent-search).

### Reddit: сначала одобрение use case

Согласно [Responsible Builder announcement](https://www.reddit.com/r/redditdev/comments/1oug31u/introducing_the_responsible_builder_policy_new/), новый OAuth-доступ требует одобрения. Соблюдайте [Data API Terms](https://redditinc.com/policies/data-api-terms), правила сохранения/удаления и ограничения коммерческого использования. Наличие старого токена или публичной страницы не даёт автоматически права на новый сценарий.

```bash
python3 scripts/collect_topics.py --topic remotion --providers reddit --approved-reddit
```

Флаг подтверждает ваше одобрение именно этого use case; не заменяет его. Поиск только ссылок/заголовков, без комментариев и полного текста, одна страница до 5 результатов. OAuth access token может истечь: ручное обновление в рамках разрешённого доступа, не смена аккаунта. [Документация поиска](https://www.reddit.com/dev/api/#GET_search).

### Приватная очередь — не публичная лента

X/Reddit записываются только в `.private/topic-review.json` с правами 0600. Каталог исключён из git, публичного сайта и release ZIP. Очередь перезаписывается при следующем явном социальном сборе. Доступность и условия публичной публикации нужно проверить отдельно; автоматического импорта очереди в ленту нет. Удалите файл после проверки, не храните дольше разрешённого срока; проверьте удаления/изменения на платформе перед дальнейшим использованием. Если проект перестаёт использовать социальные данные, удалите очередь сразу. Эта версия не реализует постоянный социальный архив и не гарантирует compliance для массовой перепубликации.

При 401/402/403/429 origin приостанавливается до следующего запуска. Нет обхода через cookies, прокси, другие аккаунты, неофициальные зеркала или закрытые репозитории.

## Postman Enterprise

Импортируйте `integrations/Motion-Radar.postman_collection.json`. Все секретные переменные пустые. Заполняйте их только локально, с секретным типом, либо используйте Postman Vault и замените ссылки переменных на vault-переменные. Не сохраняйте секреты в shared initial values, exports или публичном workspace.

В коллекции четыре **отдельно запускаемых** запроса: GitHub search, Gemini list models, X recent search, Reddit approved OAuth search. `list models` не доказывает наличие генерационной квоты. X-запрос может списать кредиты; Reddit-запрос требует одобрения. Не запускайте весь набор автоматически.

Postman API key управляет доступными вам ресурсами **Postman**, а не заменяет Gemini/X/Reddit credentials. Enterprise-функции зависят от вашей команды и администратора. Подписка Postman не подтверждена подключением к аккаунту в этом проекте. [Postman authentication](https://learning.postman.com/docs/reference/postman-api/authentication/).

## Notion Business и триалы

Notion может быть базой знаний, местом ручного исследования или системой для native Worker sync, если нужны постоянно обновляемые записи **в Notion**, а не только статический сайт. Это отдельная интеграция: Worker создаёт и ведёт свою базу, требует прав и подходящего тарифа. Здесь Worker не создан и Notion-аккаунты не объединялись.

Справка описывает [30-дневный Business-триал](https://www.notion.com/help/paid-plan-trials). Наличие Business не означает бесконечные AI-запросы и не выдаёт внешний Anthropic/Gemini API key. Проверяйте [AI credits](https://www.notion.com/help/manage-your-ai-credits), [Workers](https://www.notion.com/help/run-custom-code-with-workers) и [pricing Workers](https://www.notion.com/help/understand-pricing-for-workers). Массовые триалы и ротация аккаунтов для обхода лимитов не поддерживаются.

## Публикация и расписание

В существующий workflow добавлен бесплатный публичный сбор тем. В ручном запуске есть поле `topic`; пустое поле означает все 6 настроенных тем. По расписанию: только RSS, GitHub, прежняя локальная CPU-модель. Никакие Gemini/X/Reddit secrets автоматически не используются и платные API в workflow не включены.

Workflow публикует только заранее перечисленные файлы. Локальная `.private/` не попадает в Pages. Не заменяйте allowlist на загрузку всего каталога. Репозиторий и право на его изменение должны быть подтверждены до push.

## Что намеренно не сделано

- Нет поиска/использования чужих ключей, credential stuffing или проникновения в закрытые репозитории.
- Нет массовой регистрации/ротации триалов или злоупотребления промокодами.
- Нет обещаний «все главные статьи», полного индекса X/Reddit или безлимитных API.
- Нет проверки тарифов/остатков кредитов ваших сторонних аккаунтов без подключения.
- Нет публичного backend для мгновенного запуска сбора из браузера; скачиваемый план — не имитация выполненного задания.
