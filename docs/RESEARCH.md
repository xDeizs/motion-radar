# Исследование и выбранная архитектура

## Что было в архиве
Статический сайт Motion Radar 5: семь лент, каталог GitHub, CSS/JS-лаборатория, заметки, handoff-контекст для модели. Наличие кнопки Claude/GPT не означало автоматическую генерацию или настоящий AI-разбор.

## Agent Reach
Проверен официальный upstream: https://github.com/Panniantong/Agent-Reach
Закреплённый коммит: `7a38047acf26a729cbb27851e3cb81639da86b29`.
В проект добавлены официальный SKILL.md, лицензия и справочники; файлы учтены в skills-lock.json. CLI не устанавливался и setup не запускался. Согласно текущему upstream, для доступных публичных страниц сначала достаточно штатных инструментов. Agent Reach полезен как дополнительный read-only слой, а не обязательная зависимость статического сайта.

## Публичные источники
Проверены реальные ответы RSS/Atom для Lesterbanks, BlenderNation, Hugging Face, ComfyUI, Remotion и Rive runtime. Motionographer не включён: проверенный feed вернул некорректный XML. Ошибки не маскируются под свежие данные. Отдельные исходные ленты и GitHub API могут быть недоступны или ограничены — интерфейс показывает фактическое состояние последнего прогона.

## AI
Открытые веса https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct
Revision: `7ae557604adf67be50417f59c2c2f167def9a775`, Apache-2.0.
Работа на CPU в Transformers или через собственный Ollama. Ни бесплатные чужие API без гарантий, ни чат-подписки не выдаются за доступный production API. Генерация ограничена четырьмя новыми статьями за прогон. Отсутствие AI честно маркируется, исходник всегда доступен у автора.
