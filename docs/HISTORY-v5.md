# Motion Radar

Бесплатный самостоятельный сайт про моушен-дизайн и creative coding.
Без базы данных, платных API, AI-подписок и обязательных ключей.
Для публикации Node.js не нужен: готовый `assets/js/experience.js` лежит в репозитории.
Код — MIT; материалы сторонних авторов остаются под своими лицензиями.

## Что уже работает

- Адаптивная лента, поиск, фильтры, светлая и тёмная темы.
- Настоящий стартовый снимок RSS/Atom, не вымышленные новости.
- Семь источников: Codrops, Maxime Heckel, Blender Developers, Three.js,
  Motion, React Three Fiber, Lottie Web.
- Библиотека бесплатных ресурсов с отдельной проверкой официального указания лицензии.
- Проверка доступности ссылок, даты проверки, сохранение данных при ошибках источника.
- Личные ссылки из X / Reddit и других сайтов, закладки и JSON-экспорт/импорт.
- Готовое расписание GitHub Actions: раз в 6 часов, в `00:37 / 06:37 / 12:37 / 18:37 UTC`.
- **Motion Radar 5:** живой Three.js-hero с клавишами-ссылками, плавный скролл
  (Lenis + GSAP ScrollTrigger), закреплённые сцены, LED-видео и интерактивный радар.
  Подробности — в разделе «Motion Radar 5» ниже.

**Публикация этого проекта уже настроена:** сайт работает на GitHub Pages в
репозитории `xDeizs/motion-radar`. Инструкция ниже нужна только при переносе
архива в другой аккаунт; заново создавать репозиторий для текущего сайта не нужно.

## Опубликовать бесплатно

1. Создай **публичный** репозиторий `motion-radar` в своём GitHub-аккаунте
   с основной веткой `main`. GitHub Free поддерживает Pages для публичных
   репозиториев.
2. Загрузи **содержимое** этой папки в корень репозитория. Не загружай сам ZIP.
   Обязательно перенеси скрытую папку `.github` с файлом
   `.github/workflows/site.yml`. Если загружаешь через веб-интерфейс, этот
   файл можно добавить отдельно через **Add file → Create new file**,
   указав полный путь `.github/workflows/site.yml`.
3. В репозитории открой **Settings → Pages → Build and deployment → Source**,
   выбери **GitHub Actions**.
4. Проверь **Settings → Actions → General → Workflow permissions**:
   workflow должен иметь разрешение записывать обновлённый снимок в этот
   репозиторий. Не выдавай никаких сторонних токенов.
5. Открой **Actions → Update and publish Motion Radar → Run workflow**.
   После успешной публикации адрес появится в **Settings → Pages** и в
   результате deployment. Формат адреса — `https://<твой-логин>.github.io/motion-radar/`.

Расписание обновляет файлы данных в этом же репозитории и публикует новый снимок.
Логин, отдельный сервер и покупка домена не нужны. Сайт и публичные файлы
репозитория доступны всем — не помещай туда личные данные, токены и закрытые ссылки.
Эта версия предназначена для информационной некоммерческой ленты, не для
платного SaaS или интернет-магазина.

GitHub может задерживать или пропускать плановые задания. В публичных
репозиториях расписание может отключаться после 60 дней отсутствия активности.
Поэтому это не real-time-сервис с гарантированным временем обновления.
Если снимок старше 36 часов, интерфейс покажет предупреждение.
Стандартные hosted runners бесплатны для публичных репозиториев; не выбирай
платные larger runners и проверяй действующие лимиты своего аккаунта.

Официальная документация:
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule
- https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## Локально

Нужен только Python 3.10+:

```sh
python scripts/decode_motion_assets.py   # шрифты, картинки и видео из config/motion-assets
python -m unittest discover -s tests -v
python scripts/update.py
python -m http.server 8080
```

Открой `http://localhost:8080` на своём компьютере.

Если меняешь 3D, скролл или LED-видео, понадобится Node.js 20+ (один раз `npm install`):

```sh
npm run build    # web/experience/*.mjs → assets/js/experience.js
npm run site     # пересобрать index.html из data/feed.json без сети
npm run video    # перерисовать assets/video/led-wall.* (нужны Playwright и ffmpeg)
```
Шрифты, картинки и LED-видео хранятся в `config/motion-assets/` как base64-части
с размерами и SHA-256: GitHub MCP, через который публикуется проект, передаёт
только текст. Первая команда восстанавливает обычные WOFF2 / WebP / MP4 / WebM
в `assets/`, сборка Pages делает то же самое. После замены медиа запусти
`python scripts/pack_motion_assets.py`.

Можно открыть `index.html` напрямую: встроенный снимок, поиск, фильтры и
закладки работают без сервера. Кнопка «Проверить обновления» тогда не запрашивает
JSON. В обычном режиме эта кнопка **загружает опубликованный снимок**, а не
запускает сборщик в браузере.

## Что именно проверяется

1. **RSS/Atom:** загрузилась ли лента. До пяти последних записей каждого
   источника за 180 дней, а не полный архив. Для GitHub оставлены 1–2 последних релиза каждого проекта, чтобы версии одного инструмента не вытесняли другие материалы. Ноль записей не означает поломку:
   у проекта может давно не быть релизов. При ошибке сохраняется старый снимок
   с предупреждением. Тексты — короткие фрагменты, со ссылками на оригиналы.
2. **Адрес:** ответ HTTPS. `404/410` — адрес не найден; `401/403/429` —
   проверка ограничена; другие сбои — неизвестно. Защита сайтов не обходится.
   Успешный HTTP-ответ не подтверждает цену, безопасность загрузки, содержание
   страницы или отсутствие soft-404.
3. **Бесплатная библиотека:** отдельная официальная страница лицензии;
   ищется явное указание CC0 / MIT / GNU GPL. Показываются источник,
   найденный фрагмент, область применения и время проверки. Это **не
   юридический аудит** и не обещание бесплатности всех продуктов бренда.
4. **Раздачи и триалы:** остаются со статусом «условия не проверены».
   При истечении указанной пользователем даты — «указанный срок истёк».
   Автодетектор не выдаёт `HTTP 200` за подтверждённую акцию. Карту,
   автопродление, ограничения и лицензию нужно сверять на официальной странице.

Условия могут измениться между проверками. Перед использованием ресурса
всегда открывай оригинал. Свежие акции не выдумываются ради заполнения раздела.

## X и Reddit — вручную

Автоматические запросы к X и Reddit **не выполняются**. Платного X API и
скрейпинга в проекте нет. Для будущего Reddit API потребуется соответствующее
одобрение; эта версия работает без него.

Кнопка **Добавить ссылку** сохраняет находку только в текущем браузере.
Закладки тоже локальные; аккаунта и межустройственной синхронизации нет.
На карточках это обозначено. **Экспорт ссылок** сохраняет личные ссылки,
закладки и снимки сохранённых материалов. Импорт восстанавливает их в другом
браузере; импортированный материал не считается заново проверенным.
В режиме инкогнито / при очистке данных браузера записи могут исчезнуть.

Чтобы сознательно добавить находку в **общую публичную ленту**, заполни
`data/submissions.json`, закоммить и запусти workflow:

```json
[
  {
    "url": "https://example.com/offer",
    "title": "Название настоящей находки",
    "summary": "Проверяемые условия со слов источника, без обещаний.",
    "category": "freebie",
    "expires_at": "2026-12-01T23:59:59Z"
  }
]
```

Это только пример формата, не действующее предложение.
`category`: `manual`, `freebie` или `trial`.
Дату можно не указывать; не придумывай её. Для последнего дня в форме
используется конец дня UTC. При переносе из экспорта бери записи массива
`links`, а не весь объект экспорта.

## Поменять источники

- `config/sources.json`: HTTPS RSS/Atom и категории `motion`, `code`, `tools`. Необязательный `image_hosts` ограничивает хосты RSS-картинок, а `max_items` — число записей источника.
- `config/resources.json`: бесплатная библиотека, официальная ссылка лицензии,
  точный шаблон для поиска указания лицензии и её область применения.
- `web/index.template.html`: интерфейс. После изменений запускай
  `python scripts/update.py`, чтобы пересоздать `index.html`.

Добавляй только источники, которые разрешают такой доступ и использование
своих данных. Не включай полные статьи, API-ключи или неразрешённые приватные
материалы. Скрипт не требует сторонних Python-пакетов, использует тайм-ауты,
ограничение размера ответа и блокировку локальных/приватных адресов.

  Web Animations API, без внешних JS-библиотек. `prefers-reduced-motion` даёт
  статичный просмотр. Это шаблонный рендер, **не AI-генерация по произвольному брифу**.
- **Знания:** загрузка .md / .txt или вставка текста. До 256 КБ при импорте файла,
  200 000 символов на запись, 30 записей и 600 000 символов суммарно. Данные только
  в localStorage текущего браузера. PDF, DOCX и автоматическое скачивание полных
  статей не поддерживаются. Права на материалы остаются у авторов.
- **В работу:** Markdown-контекст для Claude / GPT / coding-агента: выбранная
  карточка или закладки, ссылки, ограничения, задача и по явному выбору — личные
  статьи. Файл сам не запускает модель. API-ключей и запросов к моделям нет.
- **Экспорт ссылок:** JSON-резервная копия теперь также включает личные тексты.
  Экспорт содержит приватные материалы: не коммить его в публичный репозиторий.

### Что автоматизировано, а что нет

После публикации GitHub Actions каждые 6 часов запускает RSS, проверку ссылок,
проверку лицензий ресурсов, чтение метаданных отслеживаемых репозиториев,
поиск новых кандидатов и проверку выбранных публичных HTML-страниц. Свежий
GitHub-кеш младше 5,5 часа повторно не запрашивается. Сбои сохраняют прошлый
снимок; время последней успешной проверки не подменяется текущим.

Это **не автономный браузерный агент по всему интернету**. Сайт не входит в
аккаунты X / Reddit, не получает приватные публикации, не обходит ограничения,
не скачивает чужие ассеты и не устанавливает найденные skills. Конкретные
публичные авторы и студии для наблюдения добавляются явно.

Claude / GPT в текущей бесплатной версии — **экспорт контекста**, не API-
интеграция. Для генерации новых сцен по расписанию потребуется отдельно выбрать
модель, её поддерживаемый API, безопасно подключить ключ и согласовать лимит
расходов. Подписка на чат и API — разные способы доступа. В коде нет
платного автоматического fallback, реквизитов или «бесплатного пробного» списания.

### Безопасность и лицензии каталога

Лицензия берётся из поля `license.spdx_id` GitHub API; отсутствие лицензии,
`NOASSERTION` и `OTHER` означают необходимость ручной проверки, а не public domain.
Даже MIT / Apache / GPL у репозитория не подтверждает права на все внешние
ассеты, услуги и зависимости. Skills прочитаны как документация, не как
инструкции для сайта. Установка и выполнение стороннего кода отключены.
Новые найденные кандидаты автоматически по коду не аудируются.

В Actions применяется только автоматически выдаваемый временный `github.token`
этого репозитория для чтения публичного GitHub API. Он передаётся только
`api.github.com`, редиректы API запрещены. Никакого личного PAT или MCP-токена
пользователя в сайт не копируется. Локальный сборщик обращается анонимно;
лимит GitHub API может ограничить поиск. Токены не записываются в снимки.

JSON не заменяет текущие данные. Локальный file://-предпросмотр работает без сети.

## Motion Radar 4 · цельный editorial-интерфейс

- Новый hero: крупная типографика + оригинальный AI material study. Это иллюстрация с небольшим pointer-параллаксом, **не живая Three.js-сцена**.
- Весь интерфейс оформлен одной системой: карточки, репозитории, референсы, лаборатория, знания, формы, диалоги, empty states и footer.
- Три визуальных входа: смотреть → референсы, делать → лаборатория, собирать → код / skills.
- Полноценные светлая и тёмная темы, системное уменьшение движения, ручной переключатель анимации, клавиатурная навигация.

## Motion Radar 5 · живой сайт

Эта версия (неон / LED, клавиши, лёд) заменяет пролог Scroll Craft v5 с серебряной
орбитой (коммит `a85b9a6`). Он остаётся в истории git и в реестре
`scrollcraft/FINGERPRINTS.md`. Что проверено — в `VERIFICATION.md`.

Сайт пересобран как одна непрерывная история: hero → манифест → три входа →
радар → библиотека → финал. Данные, вкладки, поиск, закладки, лаборатория и
приватность остались прежними — изменился способ показа.

- **Hero на Three.js.** Семь глянцевых клавиш с собственной геометрией и
  физическим материалом продолжают строки заголовка, как ряды клавиатуры. Клик ведёт
  в раздел, смайлик запускает «волну». Рядом всплывают мыльные пузыри с
  thin-film шейдером. Без WebGL показывается картинка.
- **Скролл-хореография.** Lenis сглаживает прокрутку, GSAP ScrollTrigger закрепляет
  сцены: слова манифеста загораются по одному поверх LED-стены, крест-накрест
  едут ленты, три карточки направлений проезжают горизонтально, луч радара идёт
  за скроллом и открывает реальные публикации.
- **LED-видео** нарисовано кодом (`npm run video`) и играет, только пока видно.
  Для AI-роликов есть `FLOW_PROMPTS.md`.
- **Иконки** — собственный SVG-набор с микроанимацией при наведении.
  Вкладки библиотеки выглядят как клавиши.
- **Темы:** тёмная «неон» и светлая «лёд». **Движение:** системное
  `prefers-reduced-motion` и ручной переключатель в футере выключают
  закрепления, сглаживание, видео и 3D-анимацию. Контент при этом остаётся.
- **Производительность:** 3D и видео ставятся на паузу вне экрана и в фоновой
  вкладке. Тяжёлый код вынесен в `assets/js/experience.js`, страница без него
  остаётся рабочей.

Лицензии рантайма: Three.js и Lenis — MIT, GSAP — бесплатная Standard License
от Webflow (https://gsap.com/standard-license). Шрифты — OFL 1.1. Подробности
о картинках и видео — в `IMAGE_CREDITS.md`, дизайн-решения — в разделе 14
`DESIGN_RESEARCH.md`.
