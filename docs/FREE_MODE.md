# Бесплатный режим Motion Radar

## Что собирается без платных API

- Публичные RSS/Atom: разрешённые заголовки, ссылки, даты и excerpts.
- Открытый GitHub: релизы, commits и поиск репозиториев. В Actions используется встроенный github.token, не платный внешний ключ.
- Публичный каталог Chen: название, категория и URL. Не закрытые главы.
- YouTube channel RSS может дать названия и ссылки, если ID и доступ корректны. Предыдущий feed 404 не считается подключённым; видео/субтитры автоматически не разобраны.

Расписание: light watcher раз в 30 минут; основной публичный сбор раз в 6 часов; каталог имеет 24-часовой кэш. Это best-effort расписание GitHub, не мгновенная подписка. Публичный репозиторий со стандартными GitHub-hosted runners обычно обслуживается без оплаты runner minutes; платные/larger runners не настроены. Ограничения аккаунта и правила GitHub сохраняются.

Тяжёлый локальный CPU AI теперь выключен по умолчанию. Он не вызывает платные модели, но скачивает веса и расходует вычисления. Ручной input ai или repository variable ENABLE_LOCAL_CPU_AI=true включает его отдельно. Для обычного полезного Radar он не нужен: keywords, dedup и scope работают без модели.

## Gemini: разбирать уже найденное, не покупать доступ к соцсетям

Обычная генерация у ряда моделей имеет Free Tier; требуется проверить модель, доступ проекта и фактический режим биллинга. Если проект на Paid Tier, «у модели есть бесплатный тариф» не означает, что вызов этого проекта бесплатный. Ключ сам по себе не сообщает нашему коду тариф проекта.

Пока Free Tier проекта не подтверждён, вызовы Gemini оставлены выключенными. Секрет GEMINI_API_KEY можно добавить только в GitHub Actions Secrets, не в HTML, config, README или чат. В коде текущий необязательный Gemini-режим отбирает только существующие ID из публичных фрагментов; он не является web search и не читает закрытые страницы. На 401/403/429 запуск останавливается, без обхода квот.

Free Tier может использовать ввод/вывод для улучшения продуктов Google. Не отправлять приватные уроки, client data и приватную социальную очередь.

### Почему не строим индекс Radar через Google Search grounding

В таблице цен Gemini 2.5 Flash/Flash-Lite указан бесплатный Google Search grounding с квотой, но действуют отдельные условия. Они запрещают автоматическое накопление Links для индекса, использование выдачи для выбора страниц под crawling и создание базы из Grounded Results. Поэтому бесплатная квота не даёт нам подходящий backend для базы Radar.

Grounding может быть отдельным интерактивным ответом пользователю с необходимыми Search Suggestions и источниками, но здесь он не включён и его результаты не сохраняются в feed/каталог. Для нашего индекса используем независимо полученные и разрешённые исходные источники.

Официальные ссылки:
- https://ai.google.dev/gemini-api/docs/pricing
- https://ai.google.dev/gemini-api/terms
- https://ai.google.dev/gemini-api/docs/generate-content/google-search

## Postman

Postman — клиент и среда работы с API. Его API key относится к Postman workspaces/collections/другим возможностям Postman. Он не заменяет X API credentials, не оплачивает Gemini и не запускает серверный парсер автоматически. Для бесплатного режима Radar ключ Postman вообще не требуется.

## X / Instagram / Reddit / Telegram

Не обещаем бесплатный непрерывный полный поиск по X без разрешённого доступа. Официальный X API расходует credits по тарифу; покупку/auto-recharge не включаем. Публичный веб-поиск и ссылки можно изучать вручную, но это не гарантированная полноценная social feed.

Сторонние мосты, Nitter, browser-cookie parsers и неофициальные endpoints не подключены: их доступность, права использования, утечки cookies и стабильность надо проверять отдельно. Наличие open-source кода не делает доступ к площадке бесплатным и разрешённым автоматически.

Для Telegram нужны конкретные каналы и права/необходимое согласие на AI-related использование. Public channel не равен лицензии на AI harvesting. Instagram/Reddit тоже не объявлены подключёнными по одному наличию Gemini/Postman ключа.
