# LLM research: подключение и честные границы

## Открыть новый экран

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000/?view=topics#main`. «LLM / приватка» — 10 направлений, разборы, каталог и проекты практикумов. «Motion-архив» сохраняет 6 прежних тем. `?view=research#main` — все 25 досье.

## Публичный каталог — работает без аккаунта

```bash
python3 scripts/collect_library.py
```

Только `https://chen.media/guides`, только названия/категории/ссылки. Не собирает скрытые главы. До 800 карточек и 2 МБ, без redirects; кэш 24 часа, пауза при ошибке. Порядок исходного каталога, не рейтинг. Дата наблюдения не равна дате публикации. Первый импорт не называется сотнями «новых статей».

Скрипт встроен в 6-часовой GitHub workflow; кэш не допускает повторный запрос чаще раза в сутки. Расписание реально заработает только после публикации в вашем подтверждённом репозитории и настройки Pages/Actions. Настройки подписок и лимиты GitHub проверить отдельно.

## X — реализован адаптер, доступ пока не подключён

Требуются собственный разрешённый X API use case, доступ аккаунта и подтверждение биллинга. Авторизованные вызовы могут стоить денег. Нет гарантии бесплатного доступа. Ключ не присылать в чат и не помещать в JSON/HTML/коммиты.

В защищённом окружении вашего компьютера/сервера задать `X_BEARER_TOKEN` обычным безопасным способом. Код не печатает значение и не читает чужие credentials.

Без расходов/ключа:

```bash
python3 scripts/collect_x_learning.py
```

Результат: `needs_key` или `needs_consent`, **ноль запросов**.

После проверки доступа и явного согласия на расходы:

```bash
python3 scripts/collect_x_learning.py --preset claude-skills --allow-metered --max-requests 1
```

Произвольные обычные ключевые слова (не URL, не секрет):

```bash
python3 scripts/collect_x_learning.py --query "Claude animation" --allow-metered --max-requests 1
```

Ротация всех 10 тем:

```bash
python3 scripts/collect_x_learning.py --preset all --allow-metered --max-requests 3
```

### Поведение и границы

- Последние **7 дней**, не полный архив X.
- До 3 HTTP-запросов за запуск по умолчанию; программный предел 10. По 10 posts/страницу. Расходы считаются провайдером, не по нашему числу результатов.
- Один и тот же запрос не опрашивается чаще установленной общей паузы 30 минут; все темы ротируются. Продолжение страниц сохраняется между запусками.
- Watermark продвигается только после завершения цепочки страниц. При нехватке бюджета сохраняется continuation. За пределами 7-дневного окна полнота не гарантируется.
- 401/402/403/429 останавливают текущий запуск и вводят паузу, учитывается Retry-After. В логи не попадают тело ошибки/токен. При 400 page cursor сбрасывается без продвижения watermark.
- Посты дедуплицируются по ID; сохраняется принадлежность нескольким запросам. Очередь ограничена 2000 постами, удаление старых учитывается в health.
- `note_post`/совместимый extended body используется только при наличии. Если есть лишь статья-ссылка/metadata, полный текст не придумывается и не извлекается автоматически.
- `.private/x-learning.json` — необработанные недоверенные данные и state; POSIX 0600, каталог 0700. На Windows отдельно проверить ACL. Это не автоматические инструкции агенту.
- `data/x-learning-health.json` — только статус, счётчики и безопасный код ошибки, без posts/tokens. Сайт читает только этот health.
- Реальный авторизованный вызов ещё не проверен: тесты адаптера используют fixtures. Анонимная проверка дала 401.

### Постоянный режим

Нужен собственный всегда работающий компьютер/сервер с **постоянным приватным диском**. Раз в 30 минут планировщик запускает команду из корня этого проекта с защищённым окружением. Это пример настройки, здесь он не включён:

```cron
*/30 * * * * cd /absolute/path/motion-radar && /usr/bin/python3 scripts/collect_x_learning.py --preset all --allow-metered --max-requests 3 >> /private/path/radar-x.log 2>&1
```

Не вставлять ключ в crontab. Использовать service/secret manager вашего хоста; ограничить доступ к очереди и логам. Обеспечить одного writer: не запускать этот сборщик параллельно из двух планировщиков. Внутренний кэш не является lock для конкурирующих процессов.

Не используйте публичные GitHub artifacts/cache/commits для хранения приватных постов и ключей. X-сбор намеренно не включён в публичный Pages workflow. На ephemeral runner state потеряется; это не готовое production-хранилище.

**Для публикации:** человек проверяет права, полный источник и scope, пишет короткую авторскую карточку в `config/expert_research.json`, затем `python3 scripts/update.py --render-only`. Тела постов в публичный feed автоматически не идут. Для нового dossier обновите `checked_at`, но не повышайте scope без чтения/проверки.

## Telegram, YouTube, Instagram, Reddit

Telegram: сначала конкретные ссылки и необходимые права/согласие. Массового AI-harvesting здесь нет; см. официальные Content Licensing Terms. Не обходить invite, login, email-замки или paywall.

YouTube/IG/Reddit: внешние кнопки — ручной поиск, не скрытый parser. У редакторских карточек указан scope; описание и подпись не равны просмотру видео. Полный автоматический разбор видео требует разрешённого получения транскриптов/контента и отдельного проверенного pipeline.

## Существующая Motion Studio

`studio-bridge/learning-community/` — review-only пакет. Ничего не ставит, не меняет движок/стили, не пишет индексы вручную. Продуктовая модель уточнена: **приватное обучение/workflow**, а не agency-vs-SaaS.
