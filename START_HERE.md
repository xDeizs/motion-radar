# Открыть сайт

Распакуйте архив. Перейдите в папку с `index.html` и запустите:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000 — сайт и текущий снимок уже готовы.

На Windows вместо `python3` может понадобиться `python`.

- Исходный neon-дизайн сохранён.
- Новый рабочий экран: **Обзор / AI**.
- Статьи — по оригинальным ссылкам, AI-фрагменты — на языке источника.
- Бесплатный AI-процесс и публикация GitHub Pages описаны в README.md.
- Что действительно проверено и что ещё не опубликовано — VERIFICATION.md.

Для GitHub загрузите содержимое папки в корень своего репозитория, включая `.github/`. Не загружайте один ZIP вместо файлов.
